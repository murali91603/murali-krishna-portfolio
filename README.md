# Murali Krishna Ponnaganti — Portfolio

A responsive React portfolio built with Vite, Lucide icons, and custom CSS.

## Run locally

```sh
npm install
npm run dev
```

Create a production build with `npm run build`.

## Personalize before publishing

In `src/App.jsx`, update the `PROFILE` values with verified email, LinkedIn, and GitHub details. The resume is served from `public/Murali_Cv.docx`; replace that file when updating the resume.

Project repository/demo links and certificate links were not provided. Add verified URLs to the project and certificate data to activate their links; until then, the site explains which link needs configuration.
